# Expense Tracker - Comprehensive Master Prompt & Documentation

This document serves as the master specification, architecture, and prompt for building the Expense Tracker application. 

## 1. Project Goal
Build a cross-platform (Mobile iOS/Android and Web) Expense Tracker application that allows users to manually input expenses and automatically import historical expense data by uploading Excel (`.xlsx` or `.csv`) files.

## 2. Tech Stack Definition
*   **Frontend (Mobile & Web):** React Native with Expo.
    *   Using Expo Router for navigation.
    *   TailwindCSS (via NativeWind) or standard StyleSheet for styling (clean, modern, fast).
*   **Backend & Database:** Supabase.
    *   **Supabase Authentication:** Email/Password authentication to secure user data.
    *   **PostgreSQL Database:** Relational database to store user expenses. Excellent for complex analytics queries.
    *   **Supabase Storage:** To store uploaded Excel files.
    *   **Supabase Edge Functions (Deno/TS):** A serverless function triggered to parse the Excel file using the `xlsx` package and insert the records into Postgres via the Supabase client.

## 3. Database Schema (PostgreSQL)

**Table:** `expenses`
*   `id`: uuid (primary key, auto-generated)
*   `user_id`: uuid (foreign key to auth.users)
*   `amount`: decimal
*   `category`: text (e.g., Food, Transport, Utilities, Entertainment)
*   `date`: timestamp with time zone
*   `note`: text
*   `is_imported`: boolean (true if it came from an Excel file)
*   `created_at`: timestamp with time zone

## 4. Edge Function Logic (Excel Import)
When a user uploads a file to the storage bucket:
1.  Supabase Edge Function is called (or triggered).
2.  Function downloads the file into memory.
3.  Uses `xlsx` to parse the first sheet.
4.  Maps the rows: Expects columns like `Date`, `Amount`, `Category`, `Note`.
5.  Iterates through rows and uses the Supabase client to bulk insert (`.insert()`) them into the `expenses` table.
6.  Deletes the file from Storage after successful processing to save space.

## 6. Implementation Steps for the AI / Developer
1.  **Init:** Run `npx create-expo-app@latest` to initialize the project.
2.  **Supabase Setup:** Create a Supabase project, configure the database schema (tables & policies), and install `@supabase/supabase-js`.
3.  **Auth:** Implement Supabase Auth Context in React Native.
4.  **Database & UI:** Build the Dashboard and the ability to Add/Delete expenses directly to the Postgres database.
5.  **Storage & Edge Functions:** Write the backend Deno function to parse Excel files and connect it to a file picker in the app.
6.  **Polish:** Add charts (e.g., using `react-native-chart-kit` or similar) and clean up the UI styling.
